Install Shopify app

Custom Shopify apps must be installed via Partners distribution (or a store Admin API token). Requires SHOPIFY_API_KEY, SHOPIFY_API_SECRET, and APP_URL.

1. Partners checklist (fixes “installation link is invalid”)

  1. App → Distribution → Custom distribution
  2. Add the store domain, e.g. swagdealscollection.myshopify.com
  3. Click Generate link and open it as the store owner (try incognito)
  4. App URL = {{ backend_url }}/shopify
  5. Allowed redirection URL(s) = {{ backend_url }}/shopify/callback
  6. App version scopes: only read_products, read_orders, read_customers — uncheck all other scopes, then Release

2. Open install helper

Opens a guide with Partners steps + optional direct OAuth.

3. Fallback — manual Admin API token

  1. In Shopify admin: Settings → Apps and sales channels → Develop apps → Create an app
  2. Configure Admin API scopes: read_products, read_orders, read_customers
  3. Install the app and copy the Admin API access token
  4. Go to Add store → Platform Shopify → paste shop domain + access token

After the store is connected

  1. Confirm it under Stores → Shopify
  2. Deploy theme extension from shopify/
  3. Enable AI Shopping Chat in Themes → Customize → App embeds
